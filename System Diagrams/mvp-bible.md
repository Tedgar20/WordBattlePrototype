	# MVP mental modal
	
	Battles always produce a winner
	- Ties resolved internally (submission speed, etc.)
	MVP is strictly 1v1
	Losing battles does not end a turn automatically
	A territory needs ≥ 2 troops to attack
	Turns can end by:
	- Manual end turn
	- Timer expiration
	- No valid actions remaining
	Game flow includes:
	- Main Menu
	- Battle gameplay
	- Victory screen
	- Play again / Return to menu
